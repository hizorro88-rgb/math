# 🦉 수학 놀이 (Preschool Math)

미취학 아동을 위한 듀오링고 스타일 덧셈·뺄셈 퀴즈 앱입니다.
Flutter로 만들어져 **Android와 iOS 모두**에서 동작합니다.

## 주요 기능

- 🗺️ **나이·학년별 300단계** — 4살부터 초등 3학년까지, 교육과정에 맞춘 7개 카테고리 (카테고리 첫 단계는 항상 열려 있어 내 나이에서 바로 시작)
- 🪙 **누적 점수** — 정답 +10점, 3연속 정답부터 🔥 콤보 보너스 +5점, 통과 시 별×10점 보너스
- 🐣 **칭호 성장** — 점수를 모으면 알 🥚 → 병아리 🐣 → 다람쥐 🐿️ → … → 수학 왕 👑으로 자라요
- 🦉 **부엉이 마스코트**가 홈에서 인사하고, 듀오링고식 **3D 버튼**(누르면 쏙!)으로 꾸몄어요
- 🛍️ **꾸미기 가게** — 모은 코인으로 모자·안경·친구(풍선, 곰인형…)를 사서 부엉이를 꾸며요
- 🔔 **효과음** — 정답 딩동, 콤보 아르페지오, 오답 붕~, 통과 팡파레 (홈에서 켜고 끌 수 있어요)
- ✨ **5연속 정답**부터 화면 가득 별이 팡팡 터져요
- 🗣️ **음성 읽어주기(TTS)** — "3 더하기 2는?"을 소리로 읽어 줘서 글을 몰라도 풀 수 있어요 (문제 카드의 🔊로 다시 듣기)
- 🎯 **데일리 미션** — 매일 3가지 미션(퀴즈 3판·정답 20개·별 5개)을 달성하면 보너스 코인
- 🔥 **출석 스트릭** — 매일 한 판 이상 풀면 연속 출석 일수가 이어져요
- 🔁 **틀린 문제 다시 풀기** — 틀린 문제는 판 끝에 한 번 더! 다시 맞히면 +5점 (별점은 첫 시도 기준)
- 🔢 **수 세기 모드** — "몇 개일까요?" 그림 개수 세기 (덧셈 이전 단계, 자유 연습에서 선택)
- 📊 **부모용 학습 리포트** — 최근 7일 활동, 덧셈/뺄셈/수 세기·수 범위별 정답률과 연습 추천 (홈의 📊)
- 🦉 **앱 아이콘·스플래시** — 부엉이 브랜드 아이콘과 스플래시 화면 포함 (안드로이드 어댑티브 아이콘 지원)
- 📳 정답/오답 **진동 피드백**, 오답 버튼은 **도리도리 흔들림**
- 🚪 퀴즈 도중 나가면 **"정말 그만할까요?" 확인 팝업** (실수 방지)
- 📈 묶음이 올라갈수록 **조금씩 어려워지는 커리큘럼** (3까지 덧셈 → 20까지 섞어서)
- 💾 **진행 상황 자동 저장** — 앱을 껐다 켜도 별과 잠금 해제가 유지돼요
- 🎨 **자유 연습** 모드 — 덧셈/뺄셈/섞어서, 난이도를 직접 골라서 연습
- 🍎 문제마다 **이모지 그림 힌트**로 개수 세기 연습 (뺄셈은 빼는 만큼 흐리게 표시)
- 👆 **버튼 클릭 방식** 4지선다 — 글자 입력이 필요 없어요
- 📊 듀오링고처럼 **진행 바 + 정답/오답 피드백 판**이 아래에서 나타나요
- ⭐ 한 판 10문제, 끝나면 **별점(최대 3개)과 칭찬 메시지**, 통과하면 바로 **다음 단계** 버튼

## 나이·학년별 커리큘럼 (300단계)

누리과정과 2022 개정 초등 수학 교육과정을 참고해 구성했어요.
묶음마다 10단계이고, 각 카테고리의 첫 단계는 항상 열려 있어요.

| 카테고리 | 배우는 것 | 묶음 |
|---|---|---|
| 🍼 4살 | 다섯까지 수 세기 | 수 세기 첫걸음 · 다섯까지 세기 |
| 🧸 5살 | 열까지 세기, 더하기 시작 | 열까지 세기 · 덧셈 첫걸음 |
| 🎨 6살 | 5까지 덧뺄셈, 스무까지 세기 | 뺄셈 첫걸음 · 섞어서 연습 · 스무까지 세기 |
| 🎒 7살 | 10까지 덧뺄셈 (취학 준비) | 덧셈 도전 · 뺄셈 도전 · 섞어서 도전 |
| ✏️ 초등 1학년 | 받아올림·받아내림, 20까지, 세로셈 시작 | 큰 수 덧셈/뺄셈 · 받아올림/받아내림 · 세로 덧셈/뺄셈 · 마스터 |
| 📗 초등 2학년 | 두 자리 덧뺄셈(받아올림·받아내림 세로셈), 곱셈구구 | 두 자리 덧셈/뺄셈 · 세로 덧셈/뺄셈 · 2~9단 곱셈 4개 묶음 |
| 📘 초등 3학년 | 나눗셈, 큰 수 곱셈, 세 자리 | 나눗셈 2개 묶음 · 큰 수 곱셈 · 세 자리 덧뺄셈 · 수학 왕 |

- 각 단계는 10문제, **5문제 이상(별 1개)** 맞히면 같은 카테고리의 다음 단계가 열려요.
- 곱셈은 "몇씩 몇 묶음" 그림 힌트, 나눗셈은 묶어 세기 그림 힌트가 나와요 (그림 20개 이하일 때).
- 나눗셈은 항상 나누어떨어지는 문제만 나옵니다 (곱셈구구 범위).
- 🧮 **세로셈 모드**: 일의 자리·십의 자리를 맞춰 세로로 보여주고,
  숫자 키패드로 **일의 자리부터 한 칸씩** 답을 채웁니다 (자리수 이해 학습).

## 화면 구성

1. **학습 지도(홈)** — 묶음별 단계 버튼 100개, 통과한 단계는 별 표시, 잠긴 단계는 🔒
2. **자유 연습** — 모드와 난이도를 큰 카드로 선택하고 시작
3. **퀴즈 화면** — 문제, 이모지 힌트, 큰 보기 버튼 4개, 정답 시 초록/오답 시 빨강 피드백
4. **결과 화면** — 별(최대 3개), 맞힌 개수, 다음 단계 / 다시 하기 / 지도로

## 실행 방법

[Flutter SDK](https://docs.flutter.dev/get-started/install)(3.3 이상)가 설치되어 있어야 합니다.

```bash
git clone https://github.com/hizorro88-rgb/math.git
cd math
flutter pub get
flutter run          # 연결된 기기/에뮬레이터에서 실행
```

### 릴리즈 빌드

```bash
flutter build apk    # Android APK
flutter build ios    # iOS (macOS + Xcode 필요)
```

## 출시(릴리즈) 빌드

**안드로이드 (플레이 스토어)**

1. 업로드 키스토어 만들기:
   ```bash
   keytool -genkey -v -keystore ~/upload-keystore.jks \
     -keyalg RSA -keysize 2048 -validity 10000 -alias upload
   ```
2. `android/key.properties.example`을 복사해 `android/key.properties`를 만들고 값 채우기
   (이 파일은 커밋되지 않아요)
3. 빌드: `flutter build appbundle` → `build/app/outputs/bundle/release/app-release.aab` 업로드

**iOS (앱스토어)** — macOS + Xcode 필요

```bash
flutter build ipa
```
Xcode에서 서명 팀만 지정하면 됩니다.

- 버전 올리기: `pubspec.yaml`의 `version: 1.0.0+1` (이름+빌드번호) 수정
- 스토어 설명·키워드·개인정보 문안: [`store/listing.md`](store/listing.md)
- 이 앱은 인터넷 권한을 쓰지 않고 개인정보를 수집하지 않습니다 (모든 데이터 로컬 저장)

```
lib/
├── main.dart                    # 앱 진입점, 테마

│   ├── quiz_config.dart         # 모드·난이도 설정

│   ├── curriculum.dart          # 10묶음 × 10단계 = 100단계 커리큘럼
│   └── progress.dart            # 별 계산·저장, 잠금 해제 규칙

    ├── level_map_screen.dart    # 홈: 100단계 학습 지도
    ├── practice_screen.dart     # 자유 연습(모드·난이도 선택)
    ├── quiz_screen.dart         # 퀴즈 진행 + 피드백 판
    └── result_screen.dart       # 결과(별점·다음 단계·다시 하기)
```

## 문제 출제 규칙

- 덧셈: 두 수의 합이 난이도 최대값(5 또는 10)을 넘지 않음
- 뺄셈: 답이 항상 0 이상 (음수 없음)
- 피연산자는 항상 1 이상 (`0 + 3` 같은 문제는 나오지 않음)
- 보기 4개는 정답 근처의 그럴듯한 수로 구성, 음수 없음
- 같은 문제가 연달아 나오지 않음
