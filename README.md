# 🦉 수학·한글 놀이 (Preschool Math · Korean · English · Japanese · Chinese)

미취학 아동~초등 3·4학년을 위한 듀오링고 스타일 5과목(수학·한글·영어·일본어·중국어)
퀴즈 앱입니다. Flutter로 만들어져 **Android와 iOS 모두**에서 동작합니다.

## 주요 기능

- 🗺️ **나이·학년별 420단계 수학** — 4살부터 초3·4 심화(분수·소수·시간 계산)까지, 교육과정에 맞춘 8개 카테고리 (카테고리 첫 단계는 항상 열려 있어 내 나이에서 바로 시작). 모양 세기(4살)와 시계 보기(초1)도 정식 편성
- 🔤 **영어 놀이 80단계** — 알파벳 소리 → ABC 순서·대소문자 짝 → 낱말 듣고 그림 찾기 → 스펠링 조립. **영어 낱말·알파벳은 영어(en-US) 발음**으로, 안내는 한국어로 읽어 줘요
- 🎌 **일본어 90단계 · 🀄 중국어 70단계** — 히라가나 소리·오십음 순서·낱말 조립에
  가타카나(ア~ン 소리·히라가나 짝·가타카나 낱말)까지(일본어),
  한자-그림 짝짓기·숫자 한자 一~十에 듣고 한자 찾기·한자 뜻 찾기(한자 박사)까지(중국어).
  발음은 각각 ja-JP·zh-CN 원어 TTS.
  언어 과목은 공용 "언어 팩" 구조라 새 언어를 데이터만으로 추가할 수 있어요
- 📖 **한글 놀이 120단계** — 홈에서 과목 탭(🧮 수학 / 📖 한글 / 🔤 영어 / 🎌 일본어 / 🀄 중국어)으로 전환. 그림-낱말 짝짓기 → 소리 듣고 글자 찾기(모음·자음·음절) → 글자 만들기(ㄱ+ㅏ=가)·첫소리·빈칸·낱말 조립·받침 낱말 순서로, 글자를 몰라도 소리(TTS)로 풀 수 있는 유형부터 시작. 그림이 헷갈리는 낱말(자동차/경찰차 등)은 같은 보기에 안 나와요
- 🏗️ **낱말 만들기** — 글자 타일을 순서대로 눌러 낱말을 조립해요 (쓰기 전 단계 훈련)
- 👑 **주간 보스전** — 주 1회, 여러 유형을 섞은 12문제. 통과하면 보너스 +100 코인
- 🔔 **매일 학습 알림** — 리포트(부모 게이트 안)에서 켜면 하루 한 번 "부엉이가 기다려요" 알림
- 🎲 **다양한 문제 형태** — 4지선다·세로셈 키패드에 더해 빈칸 채우기(3+□=7), 10 만들기, 큰 수 찾기, 규칙 찾기(2,4,6,?), 듣고 풀기(식을 숨긴 암산)
- 🎁 **보물상자** — 판을 통과하면 가끔 보너스 코인 상자가 나와요 (3별이면 확률 업)
- 👋 **첫 실행 온보딩** — 아이 이름·아바타·나이를 고르면 홈에서 나이에 맞는 카테고리를 👍 추천으로 표시하고, 소리가 나는지 미리 확인해요
- 🙉 **듣기 문제 안전장치** — 소리를 꺼 두었거나 기기에 한국어 TTS가 없으면, 듣기 유형 시작 전에 안내 팝업으로 알려줘요
- 🪙 **누적 점수** — 정답 +10점, 3연속 정답부터 🔥 콤보 보너스 +5점, 통과 시 별×10점 보너스
- 🐣 **칭호 성장** — 점수를 모으면 알 🥚 → 병아리 🐣 → 다람쥐 🐿️ → … → 수학 왕 👑으로 자라요
- 🦉 **부엉이 마스코트**가 홈에서 인사하고, 듀오링고식 **3D 버튼**(누르면 쏙!)으로 꾸몄어요
- 📔 **스티커북** — 퀴즈 한 판을 통과할 때마다 스티커 1장을 받고, 아이가 스티커북의 빈 자리(실루엣) 중 **원하는 곳을 직접 골라 붙여요**. 동물·간식·탈것·바다·우주 5개 테마 × 12장 = 60종. 페이지 완성 +50 🪙, 앨범 완성 +100 🪙 뒤 새 앨범 시작 (반복 수집). 모은 스티커는 🖼️ **내 꾸미기 판**(하늘·잔디 캔버스)에서 골라서 원하는 곳에 톡! 붙이고, 끌어서 옮기고, 지우개로 정리하며 자유롭게 꾸며요
- 🛍️ **꾸미기 가게** — 모은 코인으로 모자·안경·친구·배경(풀밭, 우주, 성…)을 사서 부엉이를 꾸며요 (18개 아이템, 4개 슬롯)
- 🏅 **배지 도감** — 첫 걸음부터 한 달 개근까지, 학습 기록으로 17개 배지를 모아요
- 🕒 **시계 보기** — 아날로그 시계 그림을 보고 몇 시인지 맞혀요 (자유 연습)
- 🦉 **부엉이 리액션** — 오늘 몇 판 풀었는지, 며칠째 개근인지에 따라 부엉이 인사가 달라져요
- 🔔 **효과음** — 정답 딩동, 콤보 아르페지오, 오답 붕~, 통과 팡파레 (홈에서 켜고 끌 수 있어요)
- ✨ **5연속 정답**부터 화면 가득 별이 팡팡 터져요
- 🗣️ **음성 읽어주기(TTS)** — "3 더하기 2는?"을 소리로 읽어 줘서 글을 몰라도 풀 수 있어요 (문제 카드의 🔊로 다시 듣기)
- 🎯 **데일리 미션 로테이션** — 8종 미션 풀에서 매일 3개가 뽑혀요 (한글 1판·별 3개 통과 같은 미션이 새 콘텐츠로 이끌어요)
- 🔥 **출석 스트릭 + 마일스톤** — 매일 한 판 이상 풀면 연속 출석이 이어지고, 3·7·14·30일에 보너스 코인
- 🧊 **스트릭 지킴이** — 코인 200으로 사 두면 하루 걸러도 스트릭이 이어져요 (최대 2개)
- 👨‍👩‍👧 **부모 게이트** — 부모용 리포트·이용권 화면은 곱셈 문제를 풀어야 열려요 (어린이 카테고리 심사 대응)
- 💳 **가족 이용권 (1회 결제)** — 각 과목 첫 카테고리는 무료 체험, 이용권을 사면 5과목 모든 단계 + 프로필 4명이 열려요. 스토어 가족 공유를 켜면 한 번 결제로 가족 기기에서도 사용
- ⚙️ **설정** — 효과음과 문제 읽어주기(TTS)를 따로 켜고 끄기, 말 빠르기(천천히/보통), 진도 백업 바로가기. 헤더 스피커 버튼은 한 번에 전부 끄는 마스터 스위치
- 📒 **오답 노트** — 한글·영어·일본어·중국어에서 틀린 낱말·글자 문제가 자동으로 모여요(최대 40개). 홈 배너에서 다시 풀고, 맞히면 노트에서 사라져요 (같은 문제를 또 틀리면 최신으로 올라옴)
- 🩹 **맞춤 복습** — 유형별 정답률을 보고 요즘 가장 어려워한 유형(8문제 이상 풀고 정답률 80% 미만)을 홈 배너로 제안, 한 번 눌러 바로 복습 한 판 (5과목 모든 유형 대상)
- 💾 **진도 백업·옮기기 (서버 없음)** — 리포트(부모 확인 뒤)에서 백업 코드를 만들어 메모장·메신저에 보관하면, 앱을 지웠거나 폰을 바꿔도 코드를 붙여넣어 모든 프로필의 진도·별·코인을 그대로 복원
- 👨‍👩‍👧‍👦 **넷플릭스식 프로필** — 프로필이 여럿이면 앱을 켤 때 "누가 놀까요?"부터. 프로필마다 별·코인·진도가 완전히 분리되고, 수정·삭제도 돼요
- 🔁 **틀린 문제 다시 풀기** — 틀린 문제는 판 끝에 한 번 더! 다시 맞히면 +5점 (별점은 첫 시도 기준)
- 🔢 **수 세기 모드** — "몇 개일까요?" 그림 개수 세기 (덧셈 이전 단계, 자유 연습에서 선택)
- 📊 **부모용 학습 리포트** — 최근 7일 활동, 수학 유형·수 범위·한글 유형별 정답률과 연습 추천 (홈의 📊)
- 🦉 **앱 아이콘·스플래시** — 부엉이 브랜드 아이콘과 스플래시 화면 포함 (안드로이드 어댑티브 아이콘 지원)
- 📳 정답/오답 **진동 피드백**, 오답 버튼은 **도리도리 흔들림**
- 🚪 퀴즈 도중 나가면 **"정말 그만할까요?" 확인 팝업** (실수 방지)
- 📈 묶음이 올라갈수록 **조금씩 어려워지는 커리큘럼** (3까지 덧셈 → 20까지 섞어서)
- 💾 **진행 상황 자동 저장** — 앱을 껐다 켜도 별과 잠금 해제가 유지돼요
- 🎨 **자유 연습** 모드 — 수학 16종·한글 10종 유형과 난이도(5/10/20/100까지)를 직접 골라서 연습
- 🍎 문제마다 **이모지 그림 힌트**로 개수 세기 연습 (뺄셈은 빼는 만큼 흐리게 표시)
- 👆 **버튼 클릭 방식** 4지선다 — 글자 입력이 필요 없어요
- 📊 듀오링고처럼 **진행 바 + 정답/오답 피드백 판**이 아래에서 나타나요
- ⭐ 한 판 10문제, 끝나면 **별점(최대 3개)과 칭찬 메시지**, 통과하면 바로 **다음 단계** 버튼

## 나이·학년별 수학 커리큘럼 (420단계)

누리과정과 2022 개정 초등 수학 교육과정을 참고해 구성했어요.
묶음마다 10단계이고, 각 카테고리의 첫 단계는 항상 열려 있어요.

| 카테고리 | 배우는 것 | 묶음 |
|---|---|---|
| 🍼 4살 | 다섯까지 수 세기, 모양 구분 | 수 세기 첫걸음 · 다섯까지 세기 · 모양 세기 |
| 🧸 5살 | 열까지 세기, 수 비교, 더하기 시작 | 열까지 세기 · 큰 수 찾기 · 덧셈 첫걸음 |
| 🎨 6살 | 5까지 덧뺄셈, 암산, 스무까지 세기 | 뺄셈 첫걸음 · 섞어서 연습 · 듣고 풀기 · 스무까지 세기 |
| 🎒 7살 | 10까지 덧뺄셈, □가 있는 식 (취학 준비) | 덧셈 도전 · 뺄셈 도전 · 섞어서 도전 · 빈칸 채우기 |
| ✏️ 초등 1학년 | 10의 보수, 받아올림·받아내림, 세로셈, 시계 | 큰 수 덧셈/뺄셈 · 10 만들기 · 받아올림/받아내림 · 세로 덧셈/뺄셈 · 시계 보기 · 마스터 |
| 📗 초등 2학년 | 두 자리 덧뺄셈(세로셈), 규칙 찾기, 곱셈구구 | 두 자리 덧셈/뺄셈 · 세로 덧셈/뺄셈 · 규칙 찾기 · 2~9단 곱셈 4개 묶음 |
| 📘 초등 3학년 | 나눗셈, 큰 수 곱셈, 세 자리 | 나눗셈 2개 묶음 · 큰 수 곱셈 · 세 자리 덧뺄셈 · 수학 왕 |
| 📙 초3·4 심화 | 분수, 소수, 시간 계산 | 분수 첫걸음/도전 · 소수 첫걸음/도전 · 시간 계산 |

## 한글 커리큘럼 (120단계)

미취학 아동의 한글 떼기 순서(통문자 → 소리 → 자모·조합)를 따라요.
점수·코인·미션·칭호는 수학과 함께 쌓입니다. 낱말 121개(그림 짝) 수록.

| 카테고리 | 배우는 것 | 묶음 |
|---|---|---|
| 🌱 한글 첫걸음 | 그림·소리로 낱말과 친해지기 | 낱말 보고 그림 찾기 · 그림 보고 낱말 찾기 · 모음 소리 찾기 |
| 🔤 소리와 글자 | 소리 듣고 글자 찾기 | 글자 소리 찾기 · 자음 소리 찾기 · 가나다 순서 · 첫소리 찾기 |
| ✏️ 낱말 완성 | 글자를 만들고 채워 낱말 완성 | 글자 만들기(ㄱ+ㅏ=가) · 빈칸 채우기 · 낱말 만들기(타일 조립) · 받침 낱말 · 긴 낱말 도전 |

## 영어 커리큘럼 (80단계)

소리(듣기) 먼저, 그다음 글자·낱말·스펠링 순서예요. 낱말 66개(그림 짝) 수록.
영어 낱말과 알파벳은 en-US 음성으로 읽어 줍니다.

| 카테고리 | 배우는 것 | 묶음 |
|---|---|---|
| 🅰️ 알파벳 첫걸음 | 소리로 알파벳 익히기 | 알파벳 소리 찾기 · ABC 순서 · 대문자 소문자 짝 |
| 🍎 영어 낱말 | 듣고 보며 낱말 익히기 | 낱말 듣고 그림 찾기 · 그림 보고 낱말 찾기 · 첫 글자 찾기 |
| ✏️ 스펠링 도전 | 글자를 이어 낱말 완성 | 낱말 만들기(C-A-T) · 긴 낱말 도전 |

## 일본어 커리큘럼 (90단계) · 중국어 커리큘럼 (70단계)

| 과목 | 카테고리 | 묶음 |
|---|---|---|
| 🎌 일본어 | 🌸 かな 첫걸음 | かな 소리 찾기 · あいうえお 순서 |
| 🎌 일본어 | 🍙 일본어 낱말 | 낱말 듣고 그림 찾기 · 그림 보고 낱말 찾기 · 첫 글자 찾기 |
| 🎌 일본어 | ✏️ 낱말 완성 | 낱말 만들기(ね-こ 타일 조립) |
| 🎌 일본어 | 🗼 カタカナ 도전 | カナ 소리 찾기 · 히라가나·가타카나 짝 · 가타카나 낱말 |
| 🀄 중국어 | 🐼 중국어 소리 | 낱말 소리 찾기 · 숫자 소리 찾기 |
| 🀄 중국어 | 🀄 한자 낱말 | 한자 보고 그림 찾기 · 그림 보고 한자 찾기 |
| 🀄 중국어 | 🔢 숫자 한자 | 숫자 한자 찾기 (3 → 三) |
| 🀄 중국어 | 📜 한자 박사 | 듣고 한자 찾기 · 한자 뜻 찾기(山 → 산) |

- 각 단계는 10문제, **5문제 이상(별 1개)** 맞히면 같은 카테고리의 다음 단계가 열려요.
- 곱셈은 "몇씩 몇 묶음" 그림 힌트, 나눗셈은 묶어 세기 그림 힌트가 나와요 (그림 20개 이하일 때).
- 나눗셈은 항상 나누어떨어지는 문제만 나옵니다 (곱셈구구 범위).
- 🧮 **세로셈 모드**: 일의 자리·십의 자리를 맞춰 세로로 보여주고,
  숫자 키패드로 **일의 자리부터 한 칸씩** 답을 채웁니다 (자리수 이해 학습).

## 화면 구성

1. **학습 지도(홈)** — 묶음별 단계 버튼 100개, 통과한 단계는 별 표시, 잠긴 단계는 🔒
2. **자유 연습** — 모드와 난이도를 큰 카드로 선택하고 시작
3. **퀴즈 화면** — 문제, 이모지 힌트, 큰 보기 버튼 4개, 정답 시 초록/오답 시 빨강 피드백
4. **결과 화면** — 별(최대 3개), 맞힌 개수, 다음 단계 / 다시 하기 / 지도로

## 출시(릴리즈) 빌드

**안드로이드 (플레이 스토어)**

1. 업로드 키스토어 만들기:
   ```bash
   keytool -genkey -v -keystore ~/upload-keystore.jks \
     -keyalg RSA -keysize 2048 -validity 10000 -alias upload
   ```
2. `android/key.properties.example`을 복사해 `android/key.properties`를 만들고 값 채우기
   (이 파일은 커밋되지 않아요)
3. 빌드: `flutter build appbundle` → `build/app/outputs/bundle/release/app-release.aab` 업로드

**iOS (앱스토어)** — macOS + Xcode 필요

```bash
flutter build ipa
```
Xcode에서 서명 팀만 지정하면 됩니다.

- 버전 올리기: `pubspec.yaml`의 `version` (이름+빌드번호) 수정 — 제출마다 빌드번호 증가
- 스토어 설명·키워드 문안: [`store/listing.md`](store/listing.md)
- 개인정보처리방침(호스팅 방법 포함): [`store/privacy-policy.md`](store/privacy-policy.md)
- 이 앱은 인터넷 권한을 쓰지 않고 개인정보를 수집하지 않습니다 (모든 데이터 로컬 저장)

- [ ] 플레이 콘솔: 인앱 상품 `family_pass`(비소모성) 등록, 가격 설정

## 문제 출제 규칙

- 덧셈: 두 수의 합이 난이도 최대값(5 또는 10)을 넘지 않음
- 뺄셈: 답이 항상 0 이상 (음수 없음)
- 피연산자는 항상 1 이상 (`0 + 3` 같은 문제는 나오지 않음)
- 보기 4개는 정답 근처의 그럴듯한 수로 구성, 음수 없음
- 같은 문제가 연달아 나오지 않음
