# 스토어 등록 문안 (구글 플레이 / 앱스토어)

## 앱 이름
수학·한글 놀이 — 유아 학습 게임

## 짧은 설명 (80자 이내)
부엉이와 함께 배우는 유아 수학·한글·영어·일본어·중국어 5과목 학습 게임!

## 자세한 설명

🦉 **수학·한글 놀이**는 미취학 아동부터 초등 3학년까지를 위한 학습 게임이에요.
듀오링고처럼 한 단계씩 깨면서 수학·한글과 친해집니다.

**이런 점이 좋아요**

- 🗺️ 나이·학년별 350단계 수학 지도 — 수 세기부터 곱셈·나눗셈·세로셈까지
- 🎲 다양한 문제 형태 — 빈칸 채우기, 10 만들기, 큰 수 찾기, 규칙 찾기, 듣고 풀기(암산)
- 📖 한글 놀이 120단계 — 그림-낱말 짝짓기, 소리 듣고 글자 찾기, 첫소리·빈칸·낱말 조립
- 🔤 영어 놀이 80단계 — 알파벳 소리, ABC 순서, 낱말 듣고 그림 찾기, 스펠링 조립 (영어 원어 발음)
- 🎌 일본어 60단계 — 히라가나 소리, 오십음 순서, 낱말 조립 (일본어 원어 발음)
- 🀄 중국어 50단계 — 한자-그림 짝짓기, 숫자 한자 一~十 (중국어 원어 발음)
- 🔢 수 세기 모드 — 숫자를 처음 배우는 아이도 그림을 세며 시작
- 🗣️ 문제를 음성으로 읽어 줘요 — 글을 몰라도 혼자 풀 수 있어요
- 🍎 그림 힌트 — 사과·풍선을 세면서 답을 찾아요
- 🪙 정답마다 코인이 쌓이고, 코인으로 부엉이를 꾸며요 (모자·안경·친구)
- 🎁 통과하면 가끔 보물상자가 나와요 — 보너스 코인!
- 🥚 점수가 쌓이면 칭호가 자라요 — 알 → 병아리 → … → 수학 왕!
- 🎯 매일 새로운 미션과 🔥 연속 출석으로 공부 습관 만들기
- 🔁 틀린 문제는 판 끝에 한 번 더 — 자연스러운 복습
- 📊 부모용 학습 리포트 — 유형별 정답률과 맞춤 연습 추천
- 👨‍👩‍👧‍👦 넷플릭스식 자녀 프로필 4개 — 앱을 켜면 "누가 놀까요?"로 시작, 각자 진도 분리

**안심하고 쓰세요**

- 광고 없음, 구독 없음
- 인앱 결제는 '가족 이용권' 1건뿐 (1회 결제, 스토어 가족 공유 지원)
- 각 과목 첫 카테고리는 무료로 체험할 수 있어요
- 인터넷 연결 불필요 — 모든 데이터는 기기 안에만 저장돼요
- 개인정보를 수집하지 않아요

## 개인정보처리방침 요약
이 앱은 어떠한 개인정보도 수집·전송하지 않습니다.
학습 기록은 사용자의 기기 안(로컬 저장소)에만 저장되며,
앱을 삭제하면 함께 삭제됩니다. 인터넷 권한을 사용하지 않습니다.

## 스크린샷 촬영 가이드
1. 홈 학습 지도 (진행된 프로필로, 과목 탭이 보이게)
2. 수학 퀴즈 화면 (이모지 힌트가 보이게)
3. 한글 퀴즈 화면 (그림→낱말 또는 빈칸 채우기)
4. 정답 피드백 + 콤보
5. 꾸미기 가게 (아이템 착용 상태)
6. 결과 화면 (별 3개, 보물상자가 뜨면 베스트)
7. 부모 리포트 (수학+한글 정답률)
- 태블릿 컷(10인치 / 12.9인치)도 같은 구성으로 준비
